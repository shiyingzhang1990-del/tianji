# 天机 · 图形推理训练营

一个纯前端的图形推理（图形判断推理）互动训练系统，覆盖公务员行测、事业单位、IQ 测试中的图形规律题。

## 功能

- **知识库**：图形设置、分析技巧、推理思路，8 大类规律速查 + 速记口诀
- **闯关检测**：程序即时生成题目，难度三档，即时反馈、连击得分、段位晋升
- **AI 出题**：SVG 程序化生成图形题，内置逐步解析；可接入 LLM（Kimi/DeepSeek 等 OpenAI 兼容接口）让 AI 给出推理过程
- **趣味机制**：青铜→王者段位、连击、正确率统计、今日挑战

## 技术

- Vue 3（本地打包，无 CDN 依赖）+ 纯 SVG 绘制
- 全部前端静态页，可部署到 GitHub Pages
- AI Key 仅存浏览器 localStorage，留空则使用内置解析（无需联网）

## 本地运行

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```
